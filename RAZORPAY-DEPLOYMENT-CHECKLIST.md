## Pre-Deployment Setup

### ✅ Database Setup
- [ ] Create `razorpay_settings` table in Supabase
  ```sql
  CREATE TABLE razorpay_settings (
    id INT PRIMARY KEY DEFAULT 1, enabled BOOLEAN DEFAULT false,
    razorpay_key_id TEXT, razorpay_key_secret TEXT,
    updated_at TIMESTAMPTZ DEFAULT NOW(), 
    CONSTRAINT razorpay_settings_singleton CHECK (id = 1)
  ```

## Rollback Plan

### If Issues Occur:

1. **Disable Razorpay Immediately**
   ```bash
   # Log in as admin (9223548779)
   # Click "Razorpay" tab
   # Toggle OFF
   # Click "Save Settings"
   ```

2. **Notify Customers**
   - Send email explaining temporary maintenance
   - Provide alternative payment method
   - Set timeline for fix

3. **Investigate Issue**
   - Check server logs
   - Check Razorpay Dashboard
   - Verify database connection
   - Check for API key expiration

4. **Fix & Retest**
   - Correct the issue
   - Test in staging/test environment
   - Re-enable when confident

5. **Resume Payments**
   - Toggle Razorpay back ON
   - Notify customers
   - Monitor closely

## Appendix: Common Issues & Solutions

### Issue: "Razorpay is not configured"
**Solution**: 
1. Verify razorpay_settings table exists
2. Login as admin and configure API keys
3. Toggle ON and save

### Issue: Payment verification fails
**Solution**:
1. Check that Key Secret is correct
2. Verify order ID and payment ID match
3. Check server clock is synchronized

### Issue: Admin tab not showing
**Solution**:
1. Verify logged in as 9223548779
2. Clear browser cache (Ctrl+Shift+Del)
3. Check browser console for errors
4. Verify admin-razorpay-toggle.js is loaded

### Issue: Test card rejected
**Solution**:
1. Verify using test keys (rzp_test_)
2. Double-check card number (4111111111111111)
3. Verify expiry is in future (12/25)
4. Try different test card from Razorpay docs
