## 🆘 TROUBLESHOOTING

### Pages show raw HTML instead of formatted page
- **Cause:** Wrong MIME type or server configuration
- **Fix:** Ensure files are named `.html` (not `.md` or `.txt`)
- **Check:** File should be `terms.html`, not `terms.md`

### Navigation menu not showing
- **Cause:** Pages not linked correctly
- **Fix:** Check all files are in `/public/` folder with `.html` extension
- **Check:** Open browser dev tools (F12) to check for errors

### 404 error on pages
- **Cause:** Files not in public folder or git push failed
- **Fix:** Run FINAL_DEPLOY.bat again
- **Check:** Verify files are in C:\card-blocker\public\

### Vercel build failed
- **Cause:** Usually a git push issue
- **Fix:** 
  1. Check git configuration: `git config --list`
  2. Check GitHub credentials in Windows Credential Manager
  3. Try manually: `git push origin main`
